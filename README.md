# 🌿 GreenBlend | Loja de Chás

O **GreenBlend** é uma interface de e-commerce minimalista e elegante desenvolvida para uma loja de chás orgânicos e acessórios. O projeto foca em uma experiência de usuário (UX) limpa, destacando a vitalidade e o equilíbrio que os produtos oferecem.



## ✨ Demonstração
A página conta com um design responsivo, banner hero atrativo e uma vitrine de produtos dinâmica com busca em tempo real.

## 🚀 Tecnologias Utilizadas
O projeto foi construído utilizando tecnologias web fundamentais para garantir leveza e performance:

* **HTML5**: Estruturação semântica do conteúdo.
* **CSS3**: Estilização customizada com uso de variáveis CSS e Grid Layout.
* **JavaScript (Vanilla)**: Lógica para filtragem de produtos em tempo real.
* **Lucide Icons**: Biblioteca de ícones vetoriais modernos e leves.

## 🛠️ Funcionalidades
* **Busca em Tempo Real**: Filtre os produtos da vitrine instantaneamente enquanto digita no campo de pesquisa.
* **Design Responsivo**: Layout adaptável para dispositivos móveis, tablets e desktops.
* **Interface Moderna**: Uso de sombras suaves, arredondamentos (`border-radius`) e efeitos de hover para melhor interatividade.
* **Sticky Navigation**: Barra de navegação que acompanha a rolagem da página.
