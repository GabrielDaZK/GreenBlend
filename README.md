# ☕ GreenBlend | Loja de Chás Orgânicos

A **GreenBlend** é uma interface de e-commerce moderna e minimalista desenvolvida para proporcionar uma experiência relaxante e eficiente na compra de chás e acessórios. O projeto foca em design limpo, responsividade e busca dinâmica de produtos.

---

## 🚀 Funcionalidades

* **Busca em Tempo Real:** Filtro inteligente que atualiza a lista de produtos conforme o usuário digita.
* **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
* **Interface Intuitiva:** Cards de produtos organizados com foco em imagens de alta qualidade.
* **Ícones Dinâmicos:** Integração com a biblioteca Lucide para uma interface moderna.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais:

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização com variáveis, Flexbox e CSS Grid.
* **JavaScript (ES6+):** Lógica de busca e manipulação do DOM.
* **Lucide Icons:** Biblioteca de ícones via CDN.
